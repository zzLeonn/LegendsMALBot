# LegendsMALBot

A Telegram anime bot built with Python and SQLite, featuring fast anime search, inline mode support, and anime information lookup.

## Features

- 🔎 Anime search with fuzzy matching
- ⚡ Inline search support
- 📚 SQLite database storage
- 🖼️ Anime posters and thumbnails
- 🎯 Fast and user-friendly results

## Commands

| Command | Description |
|----------|-------------|
| /start | Start the bot |
| /search | Search for an anime |
| Inline Mode | Search directly from any chat |

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/LegendsMALBot.git
cd LegendsMALBot
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a `.env` file

```env
BOT_TOKEN=your_bot_token
```

4. Run the bot

```bash
python bot.py
```

## Requirements

- Python 3.10+
- python-telegram-bot v22+
- SQLite
